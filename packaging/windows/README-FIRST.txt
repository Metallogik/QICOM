QICOM for Windows - portable version
====================================

This is the version that is not installed. To install QICOM as a regular
program (in Program Files, with a Start menu entry and uninstallation from
Settings > Apps), use QICOM-windows-x64.zip instead: extract it and
double-click QICOM-Setup.exe.

To use this version: right-click the zip file > "Extract All...", open the
extracted QICOM-windows-x64 folder and double-click qicom.exe. Do not
launch qicom.exe from inside the zip: Windows extracts only that file and
the application does not start. Full instructions: TESTER-GUIDE.txt.
